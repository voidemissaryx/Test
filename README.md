# 🟣 VOIDCORE

### A Modern VPN Experience

**VOIDCORE** is a modern VPN application focused on simplicity, performance, and user experience. It provides an intuitive environment for managing server configurations and establishing VPN connections.

## ✨ Features

- 🔐 Secure and private connections
- ⚡ Smart Connect for automatic server selection
- 🌐 V2Ray configuration support
- 📡 Server and configuration management
- 🔄 Easy connection and disconnection
- 🎨 Modern interface with a dark purple theme
- 📱 Designed for a smooth mobile experience

## 🌐 About VOIDCORE

VOIDCORE aims to make VPN connectivity simple and accessible through a clean interface and practical features.

Whether you prefer selecting a server manually or using Smart Connect, VOIDCORE gives you control over your connection in one place.

## 🛠️ Technologies

- Flutter
- Dart
- Xray-core
- V2Ray
